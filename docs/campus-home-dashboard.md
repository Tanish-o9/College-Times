# Campus Home Dashboard

Personalized dashboard landing for College Times.

## Widgets

*   **Active Incident Strip**: Highlight critical emergency alerts in real-time.
*   **Quick Actions Row**: Access standard creator tools (posts, events, polls, group moments).
*   **Unread Activity Banner**: Highlights notifications needing attention.
*   **Joined & Trending Groups**: Fast list access.
*   **Upcoming Events & Opportunities**: Bounded overview widget listings.

## Personalized Scoring

Sorts groups, events, and opportunities based on the student's department, interests, batch year, and group membership vectors.

*   Each section maintains a hard query limit of **5 items** to prevent excessive reads.
